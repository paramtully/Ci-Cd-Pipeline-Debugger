# Ci-Cd-Pipeline-Debugger

A CLI tool: `pipedebug run` — runs your **GitHub Actions** jobs locally via [nektos/act](https://github.com/nektos/act) (+ Docker) and uses AI to debug minor failures (patch → re-run).
